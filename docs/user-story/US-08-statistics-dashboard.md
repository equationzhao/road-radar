# US-08: 统计数据与仪表盘

**作为一名** 骑行者，
**我希望能** 查看骑行统计和路书库的概览，
**以便** 追踪骑行进度并了解骑行模式。

## 验收标准

### 路书库概览
- [ ] 路书总数、总距离、总爬升
- [ ] 路书按类型分布（饼图：平路 / 起伏 / 丘陵 / 山地）
- [ ] 路书按难度分布（柱状图）
- [ ] 标签云，展示最常用的标签
- [ ] 地理热力图，所有路书绘制在地图上

### 骑行活动摘要
- [ ] 每月/每年骑行次数时间线图表
- [ ] 累计骑行距离随时间变化
- [ ] 累计爬升随时间变化
- [ ] 最长骑行、最难骑行、骑得最多的路书
- [ ] 骑行连续打卡追踪（连续天数/周数）

### 路书洞察
- [ ] 路书平均指标（距离、爬升、难度）
- [ ] "未骑路书"数量——已导入但从未骑行的路书
- [ ] "过期收藏"——收藏但 3 个月以上未骑的路书
- [ ] 难度进阶趋势（是否在挑战更难的路书？）

### 个人记录
- [ ] 单次最长骑行（距离）
- [ ] 单次最大爬升
- [ ] 单月最多骑行次数
- [ ] 完成的最高难度路书（按难度评级）

## 边界情况
- 尚无骑行数据（只有路书，无骑行记录）——显示导入统计，鼓励记录骑行
- 路书库中仅一条路书——显示统计但无对比上下文
