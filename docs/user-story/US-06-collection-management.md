# US-06: 路书收藏与管理

**作为一名** 骑行者，
**我希望能** 将路书整理到收藏集中并高效管理，
**以便** 随着路书库的增长保持结构清晰、便于浏览。

## 验收标准

### 收藏集
- [ ] 创建命名收藏集（如"高山垭口"、"周末环线"、"砾石探险"）
- [ ] 将路书添加到一个或多个收藏集
- [ ] 从收藏集中移除路书（不删除路书本身）
- [ ] 在收藏集中拖拽排序路书
- [ ] 设置收藏集封面图（自动取第一张路书封面，或手动设置）
- [ ] 为收藏集添加描述/说明

### 收藏与心愿单
- [ ] 将路书标记为"收藏"（快速访问列表）
- [ ] 创建"待骑"心愿单
- [ ] 将路书标记为"已骑"并记录日期

### 批量操作
- [ ] 多选路书进行批量操作：
  - 添加到收藏集
  - 添加/移除标签
  - 删除
  - 导出
- [ ] 批量导入：一次上传多个 GPX 文件
- [ ] 拖拽多个文件到应用进行批量导入

### 路书管理
- [ ] 导入后编辑路书名称
- [ ] 删除路书时显示确认对话框
- [ ] 复制路书（创建副本供修改）
- [ ] 归档路书（从主视图隐藏，保留在收藏集中）
- [ ] 查看路书历史：导入日期、所有编辑、骑行记录

### 展示模式
- [ ] 卡片视图（带封面图和关键指标的卡片布局）
- [ ] 列表视图（紧凑的可排序表格）
- [ ] 地图视图（所有路书绘制在同一张地图上）
- [ ] 切换视图时保留排序/筛选状态

## 边界情况
- 删除属于多个收藏集的路书——警告所有受影响的收藏集
- 空收藏集——显示占位提示，引导添加路书
- 收藏集中 100+ 条路书——分页或虚拟滚动
