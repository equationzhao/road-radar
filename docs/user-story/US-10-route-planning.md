# US-10: 路线规划与编辑

**作为一名** 骑行者，
**我希望能** 从零创建新路书或修改已导入的路书，
**以便** 根据需求自定义路线，无需切换到其他工具。

## 验收标准

### 路线创建
- [ ] 在地图上点击航点创建路书
- [ ] 航点之间自动规划路线（使用路线引擎沿道路/路径计算）
- [ ] 支持手动模式：自由放置点，不自动规划
- [ ] 创建时设置路书名称、描述和标签

### 路线编辑
- [ ] 通过拖拽添加/删除/重排航点
- [ ] 在选定点将一条路书拆分为两条
- [ ] 合并两条路书为一条（连接端点）
- [ ] 反转路线方向
- [ ] 裁剪路书（删除起始/末尾段）
- [ ] 从折返路线创建环线

### 海拔剖面编辑
- [ ] 手动修正海拔（针对已知 GPS 不准确的情况）
- [ ] 使用 DEM（数字高程模型）数据重新计算海拔剖面
- [ ] 平滑处理噪声大的海拔数据，滤波强度可配置

### 路线分段
- [ ] 在路书上标记命名区段（如"XX 垭口爬坡"、"山谷下坡"）
- [ ] 设置区段类型：爬坡、下坡、平路、休息点、兴趣点
- [ ] 查看各区段的详细统计

## 边界情况
- 无自动路线规划的路段（越野）——允许手动放置点
- 编辑已有骑行记录的路书——警告影响，提供复制选项
- 合并不相连的路书——自动规划端点间路线或发出警告
