# US-07: 路书分享与导出

**作为一名** 骑行者，
**我希望能** 与朋友分享路书并将路书导出到其他平台/设备，
**以便** 他人可以使用我的路书，我也可以在码表上使用。

## 验收标准

### 导出格式
- [ ] 导出为 GPX（标准格式，兼容性最广）
- [ ] 导出为 TCX（Garmin 兼容）
- [ ] 导出为 KML（Google Earth）
- [ ] 导出路书 + 笔记 + 标签的打包文件
- [ ] 批量导出多条路书

### 设备集成
- [ ] 导出带有路书指引航点的 GPX（如有）
- [ ] 为 Garmin/Wahoo/Hammerhead 优化 GPX（减少点数以适应设备内存限制）
- [ ] 生成可分享的路书链接（网页查看器，无需账号即可浏览）

### 分享功能
- [ ] 生成路书公开链接（只读视图，含地图、剖面图、笔记）
- [ ] 分享路书到社交媒体，自动生成路书卡片图
- [ ] 路书链接的二维码（方便手机扫码分享）
- [ ] 嵌入路书地图到外部网站（iframe 嵌入代码）
- [ ] 通过邮件分享（附带路书预览）

### 隐私控制
- [ ] 设置路书可见性：仅自己 / 仅链接可访问 / 公开
- [ ] 隐藏精确起终点位置（在家庭住址周围设置隐私缓冲区）
- [ ] 从导出文件中剥离个人数据（心率、功率）
- [ ] 为分享链接设置密码保护

## 边界情况
- 导出无 GPS 数据的路书——阻止导出并显示清晰提示
- 访问已删除路书的分享链接——显示"路书已不可用"
- 超长路书导出到设备——提供减少点数的选项并预览效果
