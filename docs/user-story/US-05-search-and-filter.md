# US-05: 搜索与筛选路书

**作为一名** 骑行者，
**我希望能** 按多种条件搜索和筛选路书，
**以便** 快速找到适合今天骑行的路书。

## 验收标准

### 文本搜索
- [ ] 按路书名称搜索（模糊匹配）
- [ ] 按城市/区域/位置搜索
- [ ] 按笔记内容搜索（全文检索）
- [ ] 按标签搜索
- [ ] 输入时显示搜索建议/自动补全

### 数值筛选
- [ ] 按距离范围筛选（滑块 + 手动输入，如 20-50km）
- [ ] 按爬升范围筛选（如 500-1000m）
- [ ] 按难度评级筛选（如 >= 3 星）
- [ ] 按体验评分筛选
- [ ] 按最大坡度筛选（如 < 15%）

### 分类筛选
- [ ] 按骑行类型筛选（平路 / 起伏 / 丘陵 / 山地）
- [ ] 按标签筛选（多选，支持 AND/OR 逻辑）
- [ ] 按路面类型筛选
- [ ] 按路况质量筛选
- [ ] 按风景类型筛选

### 时间筛选
- [ ] 按导入日期范围筛选
- [ ] 按最近骑行日期范围筛选
- [ ] 按骑行次数筛选（如骑过 0 次、骑过 > 3 次）
- [ ] 排序方式：名称、距离、爬升、导入日期、最近骑行、难度、评分、骑行次数

### 筛选界面
- [ ] 多个筛选条件默认使用 AND 逻辑组合
- [ ] 显示已激活的筛选标签，每个标签可单独清除
- [ ] 一键"清除所有筛选"
- [ ] 保存筛选预设（如"周末长距离"、"轻松恢复骑"）
- [ ] 筛选变化时实时显示结果数量
- [ ] 地图视图：仅在地图上显示符合当前筛选的路书

## 边界情况
- 无搜索结果——显示友好提示，建议放宽筛选条件
- 超大路书库（1000+ 条）——确保搜索性能，分页加载
- 筛选条件冲突导致零结果——高亮标出冲突的筛选条件
