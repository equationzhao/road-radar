# US-01: 导入与解析 GPX 路书

**作为一名** 骑行者，
**我希望能** 导入 GPX 文件到系统中，
**以便** 路书被自动解析，关键指标无需手动填写即可提取。

## 验收标准

### 基本信息提取
- [ ] 系统解析 GPX 文件并提取：总距离、总爬升、总下降、起终点坐标、最低/最高海拔
- [ ] 根据 GPS 坐标自动识别所在城市/区域（反向地理编码）
- [ ] 显示路书名称（取自 GPX 元数据或文件名）
- [ ] 基于平均速度假设显示预估骑行时间（可配置）
- [ ] 解析 GPX 中的时间戳（创建日期、持续时间）

### 路线可视化
- [ ] 在交互式地图上绘制路线
- [ ] 起点和终点使用不同图标标记
- [ ] 支持 GPX 1.0 和 GPX 1.1 格式
- [ ] 支持文件上传导入（拖拽 + 文件选择器）
- [ ] 支持通过 URL 导入（如 Strava、Komoot 导出链接）

### 数据校验
- [ ] 解析前验证 GPX XML 结构
- [ ] 对无效/损坏的文件显示清晰的错误提示
- [ ] GPX 不含轨迹点时发出警告
- [ ] 大文件（> 10MB）平滑处理，显示进度条

### 重复检测
- [ ] 检测是否已存在相似路书（基于起终点坐标 + 距离相似度）
- [ ] 允许用户选择：作为新路书导入 / 关联已有路书 / 取消

## 边界情况
- GPX 包含多条轨迹（多日骑行）——允许选择导入哪条轨迹，或全部导入
- GPX 只有航点没有轨迹——在地图上显示航点，警告缺少轨迹数据
- 极短路书（< 1km）——仍然导入，但标记为可能不完整
