# US-04: 骑行日记与骑后记录

**作为一名** 骑行者，
**我希望能** 在骑行完成后记录感受、评价体验并添加图片/视频，
**以便** 建立个人骑行日志，日后回顾骑行体验。

## 验收标准

### 骑行笔记（核心）
- [ ] 为每条路书撰写自由文本骑行感想/描述
- [ ] 笔记支持 Markdown 格式（标题、加粗、列表、链接）
- [ ] 自动保存草稿，防止数据丢失
- [ ] 记录笔记的创建时间和最后编辑时间
- [ ] 同一条路书支持多次骑行记录（每次骑行添加一条新记录）
- [ ] 笔记以文字为主，重点是感受、体验、路况变化等主观信息

### 评价与快捷反馈
- [ ] 对骑行体验进行评分（1-5 星，与难度评级分开）
- [ ] 快捷反应按钮："还想骑"、"推荐"、"需改善"
- [ ] 记录实际骑行日期
- [ ] 可选填写天气状况

### 外部链接
- [ ] 可选添加 Strava 骑行记录链接（纯 URL，点击跳转浏览器打开）
- [ ] 可选添加其他外部链接（如 Komoot、骑行 app 记录）
- [ ] 不解析、不导入外部链接的数据，仅作为参考跳转

### 媒体附件
- [ ] 上传照片（拖拽 + 文件选择器，每条记录最多 20 张）
- [ ] 上传或链接视频（支持本地上传 + YouTube/B站链接）
- [ ] 为上传的图片自动生成缩略图
- [ ] 通过拖拽重新排列照片顺序
- [ ] 为单张照片添加说明文字
- [ ] 将某张照片标记为路书"封面图"
- [ ] 自动压缩/缩放上传的图片（保留原图供下载）

## 不做什么
- 不导入骑行记录数据（GPX/TCX/FIT 等）
- 不记录骑行统计数据（速度、功率、心率、卡路里等）
- 不做路线偏差分析
- 运动数据留给 Strava 等专业工具，这里只做路书管理 + 感受记录

## 边界情况
- 上传超大照片（> 10MB）——压缩时保持画质
- 上传不支持的视频格式——显示支持格式列表，建议转换工具
- 同一天多次骑行——允许，通过时间戳区分
- 无文字仅有图片的记录——允许（纯图片记录有效）
- Strava 链接格式校验——接受任意 URL，strava.com 链接显示图标
