# US-03: 标签与难度评级

**作为一名** 骑行者，
**我希望能** 为路书添加自定义标签并评定难度等级，
**以便** 组织我的路书库并快速找到符合偏好的路书。

## 验收标准

### 自定义标签
- [ ] 创建自定义文本标签（如"砾石路"、"好路"、"烂路"、"风景好"、"无车"）
- [ ] 一条路书可添加多个标签
- [ ] 可从路书中移除标签
- [ ] 输入时自动联想已有标签库中的标签
- [ ] 支持标签颜色编码（用户自定义或系统预设）
- [ ] 显示标签在所有路书中的使用次数

### 预设标签分类
- [ ] 路面类型：柏油路、砾石路、土路、石板路、混合路面
- [ ] 路况质量：优秀、良好、一般、差
- [ ] 风景类型：海滨、山景、森林、城市、农田、荒漠
- [ ] 车流情况：无车、少车、中等、拥堵
- [ ] 配套设施：有自行车道、有休息点、有水源、附近有车店

### 难度评级
- [ ] 每条路书 1-5 星评级系统
- [ ] 悬停/触摸时显示评级参考标准：
  - ⭐ - 轻松，平路，短距离，好路面
  - ⭐⭐ - 中等，有一些坡，中等距离
  - ⭐⭐⭐ - 有挑战，显著爬坡或长距离
  - ⭐⭐⭐⭐ - 困难，大爬坡，长距离，或技术性强
  - ⭐⭐⭐⭐⭐ - 极限，高山垭口，超长距离，或极端坡度
- [ ] 可选的分项难度评级：
  - 体能难度（距离 + 爬升）
  - 技术难度（路面状况、下坡技术）
  - 导航难度（找路复杂度）
- [ ] 路书分享后可显示社区平均评分（与个人评分并列）

### 自动推荐元数据
- [ ] 系统根据路书数据推荐路面类型（公路 vs 小径，GPX 中的轨迹类型）
- [ ] 系统根据距离、爬升和坡度分析推荐难度
- [ ] 用户可接受、修改或拒绝推荐

## 边界情况
- 标签文字过长——截断显示，悬停时展示完整文本
- 矛盾标签（如"平路" + "山地"）——警告用户但允许
- 无标签的评级——允许，不强制要求
