# US-11: 用户设置与数据管理

**作为一名** 骑行者，
**我希望能** 按自己的偏好配置应用并管理数据，
**以便** 工具能贴合我的骑行习惯。

## 验收标准

### 用户配置
- [ ] 设置偏好单位（公制 / 英制）
- [ ] 设置家庭位置（用于"附近路书"、隐私缓冲区）
- [ ] 设置默认地图样式（街道 / 卫星 / 地形 / 骑行专用）
- [ ] 设置骑行类型偏好（公路 / 砾石 / 山地 / 旅行）

### 显示偏好
- [ ] 选择海拔图样式（填充 / 线条 / 渐变色）
- [ ] 选择路书列表默认排序方式
- [ ] 选择默认视图模式（卡片 / 列表 / 地图）
- [ ] 配置坡度颜色阈值（多少 % 算"陡"）
- [ ] 配置难度评级参考标准（个人校准）

### 数据管理
- [ ] 将所有数据导出为 JSON/ZIP（完整备份）
- [ ] 从备份恢复数据
- [ ] 按条件批量删除路书（如删除所有 0 次骑行且超过 1 年的路书）
- [ ] 存储用量概览（照片/视频占用了多少空间）
- [ ] 压缩旧媒体文件以节省空间

### 平台导入/同步
- [ ] 从 Strava 导入路书（批量导入收藏的路线）
- [ ] 从 Komoot 导入路书
- [ ] 从 RideWithGPS 导入路书
- [ ] 与 Strava 同步（自动将新活动导入为骑行记录）

## 边界情况
- 从数据格式不同的平台导入——映射字段，警告不支持的元数据
- 从备份恢复时存在冲突路书——提供合并策略选项
- 更改单位时已有数据——所有显示更新，存储数据不变
