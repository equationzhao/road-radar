# US-02: 路线剖面与海拔图

**作为一名** 骑行者，
**我希望能** 查看路书的距离-海拔剖面和地形分类，
**以便** 在决定骑行前快速评估体能需求。

## 验收标准

### 海拔剖面图
- [ ] 显示交互式距离-海拔截面图（X 轴为距离，Y 轴为海拔）
- [ ] 鼠标悬停/触摸显示该点的精确海拔、距离和坡度
- [ ] 在剖面图上悬停时，地图上高亮对应位置（双向联动）
- [ ] 显示关键统计叠加层：最大坡度、平均坡度、最陡 1km 区段
- [ ] 支持缩放查看剖面图的特定区段

### 坡度分析
- [ ] 按坡度等级对海拔剖面进行颜色编码：
  - **平路**：0-3%（绿色）
  - **起伏**：3-6%（黄色）
  - **中等爬坡**：6-9%（橙色）
  - **陡坡**：9-12%（红色）
  - **极端**：>12%（深红色）
- [ ] 显示坡度分布饼图/柱状图
- [ ] 自动识别并标注爬坡区段（持续 > 3% 坡度且距离 > 500m）

### 地形分类
- [ ] 根据剖面分析自动分类骑行类型：
  - **平路型** - 每 10km 总爬升 < 10m
  - **起伏型** - 中等起伏，无持续爬坡
  - **丘陵型** - 显著爬坡，每 10km 爬升 > 20m
  - **山地型** - 大规模爬坡，每 10km 爬升 > 50m
- [ ] 在路书卡片上以徽章/标签形式显示骑行类型
- [ ] 允许手动覆盖自动分类结果

### 爬坡区段
- [ ] 从海拔剖面自动检测单个爬坡
- [ ] 每个爬坡显示：距离、爬升高度、平均坡度、最大坡度
- [ ] 按难度对爬坡分级（采用公路车爬坡分类：Cat 4 → HC）
- [ ] 在地图上高亮显示爬坡区段

## 边界情况
- 无显著海拔变化的路书——显示平路徽章，隐藏爬坡详情
- 超长路书（> 200km）——确保图表渲染性能（必要时降采样）
- GPS 海拔数据噪声大——应用平滑滤波，标注海拔为 GPS 推算值
